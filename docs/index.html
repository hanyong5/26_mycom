Supabase 설정

환경변수는 .env 파일에서 관리합니다. .env.example을 복사하여 사용하세요.
클라이언트는 src/lib/supabase.js에서 단일 인스턴스로 초기화합니다.

VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key

데이터베이스 스키마

profiles → posts 순으로 외래키가 연결됩니다.
profiles.role 컬럼으로 user / admin 권한을 구분합니다.

profiles — 회원 프로필

create table public.profiles (
  id         uuid          primary key
               references auth.users(id) on delete cascade,
  name       varchar(50)  not null,
  phone      varchar(20),
  zipcode    varchar(10),
  address1   varchar(255),
  address2   varchar(255),
  role       varchar(20)  default 'user'
               check (role in ('user', 'admin')),
  avatar_url text,
  created_at timestamptz   default now(),
  updated_at timestamptz   default now()
);

posts — 게시글

create table public.posts (
  id         bigint        generated always as identity primary key,
  user_id    uuid          not null
               references public.profiles(id) on delete cascade,
  title      varchar(200) not null,
  content    text          not null,
  created_at timestamptz   default now(),
  updated_at timestamptz   default now()
);

코딩 규칙

  • 컴포넌트는 함수형으로 작성, Props는 구조분해할당 사용
  • Supabase 호출은 services/ 레이어에 집중 — 컴포넌트에서 직접 호출 금지
  • 에러 처리는 try/catch로 일관되게 처리, 사용자에게 toast 또는 인라인 메시지로 표시
  • Tailwind 클래스는 컴포넌트 내부에서만 사용 — 인라인 style 속성 지양
  • 환경변수에 민감 정보 저장 — 코드에 API 키 하드코딩 금지

Supabase MCP 연결

Claude Code에서 Supabase MCP를 통해 DB를 직접 조작합니다.
.claude/settings.json 또는 claude_desktop_config.json에 아래 설정을 추가하세요.

1. MCP 서버 설정

{
  "mcpServers": {
    "supabase": {
      "command": "npx",
      "args": [
        "-y",
        "@supabase/mcp-server-supabase@latest",
        "--access-token",
        "<SUPABASE_PERSONAL_ACCESS_TOKEN>"
      ]
    }
  }
}

Access Token 발급: Supabase 대시보드 → Account → Access Tokens

2. 연결 후 사용 가능한 작업

MCP 도구설명
list_projects프로젝트 목록 조회
list_tables테이블 목록 확인
execute_sqlSQL 직접 실행 (마이그레이션 등)
apply_migration스키마 마이그레이션 적용
get_logs서버 로그 조회
get_advisors성능 / 보안 권고사항 확인
generate_typescript_typesDB 스키마 기반 TypeScript 타입 자동 생성

3. profiles 자동 생성 트리거

회원가입 시 auth.users 레코드 생성과 동시에 profiles에 자동으로 행을 삽입합니다. 

create or replace function public.handle_new_user()
returns trigger as $$
begin
  insert into public.profiles (id, name)
  values (new.id, coalesce(new.raw_user_meta_data->>'name', ''));
  return new;
end;
$$ language plpgsql security definer;

create trigger on_auth_user_created
  after insert on auth.users
  for each row execute procedure public.handle_new_user();
